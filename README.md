## 💡 Approach Explanation

### 🔴 Brute Force Approach
- Simple and direct solution  
- Uses basic loops or naive logic  
- Higher time complexity (often O(n²) or more)  

### 🟢 Optimized Approach
- Uses efficient algorithms or data structures  
- Reduces time complexity (O(n), O(log n), etc.)  
- More scalable and performance-friendly
